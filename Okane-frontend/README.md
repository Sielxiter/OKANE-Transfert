# Frontend Okane Transfer

Ce projet Angular contient l'interface web de Okane Transfer.

## Serveur de développement

Pour démarrer le serveur local :

```bash
pnpm start
```

L'application est ensuite disponible sur `http://localhost:4200/` et se recharge automatiquement après modification des fichiers sources.

## Génération de code

Pour générer un composant avec Angular CLI :

```bash
ng generate component nom-du-composant
```

Pour consulter la liste complète des schémas disponibles :

```bash
ng generate --help
```

## Compilation

Pour compiler le projet :

```bash
pnpm build
```

Les artefacts compilés sont générés dans le dossier `dist/`.

## Tests unitaires

Pour exécuter les tests avec Vitest :

```bash
ng test
```

## Tests de bout en bout

Pour les tests de bout en bout :

```bash
ng e2e
```

Angular CLI ne fournit pas de framework de test de bout en bout par défaut. Choisir l'outil adapté au besoin du projet.
